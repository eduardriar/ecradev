# ¿Cómo se construyó este sitio?

No tengo pena en decir que construí este sitio usando IA (Cursor + Claude), y soy un desarrollador frontend capaz de construir este tipo de aplicaciones. Sin embargo, creo que es momento de sumarse al entusiasmo por la IA. Venía aplazando la actualización de mi portafolio, que incluye varias funcionalidades nuevas que quiero mostrar y publicar, y ahora que la IA explotó decidí experimentar con esto y construir mi nuevo portafolio. En este post voy a documentar todo lo que encontré relacionado con IA + desarrollo.

## Cómo empecé este proyecto

1. Tomé como referencia/motivación este video de Platzi (Así se desarrolla en 2026)[https://www.youtube.com/watch?v=FyeHZH2jeOk]
2. Instalé Claude + Cursor
3. Aprendí las opciones de Claude para descubrir de qué es capaz esta herramienta. Habilité la opción /plan para empezar a construir el sitio.
4. Este fue el prompt que usé para empezar el portafolio.

## Contexto
  Construir un sitio web de portafolio personal para un desarrollador Frontend. El sitio debe mostrar el trabajo, las habilidades y alojar una sección de blog llamada "Dev Notes". El diseño es minimalista y limpio, con animaciones sutiles al hacer scroll.

## Stack tecnológico
- **Framework:** Next.js 14 (App Router)
- **Estilos:** Tailwind CSS
- **Blog:** archivos MDX (renderizados en build vía `next-mdx-remote` o `@next/mdx`)
- **Animaciones:** Framer Motion (fade-in / slide-up al hacer scroll)
- **Formulario de contacto:** EmailJS (sin backend) o Resend
- **Listo para desplegar:** compatible con Vercel

## Hallazgos después de que la IA construyó el sitio

Quedé realmente impresionado por lo que es capaz Cursor; mi primer pensamiento fue "ese es el trabajo que hago yo". Más adelante encontré cosas que cambiaron mi opinión: puede depender de qué tan específico fui al darle las indicaciones a la IA. A pesar de que el código está muy bien organizado y es de buena calidad, creo que como desarrolladores de la nueva era debemos revisarlo y entender cómo fue escrito. Noté que no había nada de componentización, y eso es importante para mantener una buena estructura del proyecto. Encontré este problema al modificar el componente Header.tsx y decidí crear nuevos componentes para mejorar la legibilidad.
